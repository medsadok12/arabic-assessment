# مصاريف 💍 — دفتر مشترك لمصاريف تحضيرات الزواج

تطبيق ويب مستقل ومبسّط يتشاركه الخطيبان لتسجيل مصاريف الزواج والمستحقات القادمة
حتى يوم الزفاف: كل ما يضيفه أحدهما يظهر عند الآخر خلال لحظة.

## المزايا

- **إدخال سريع**: البيان، السعر (يقبل الأرقام العربية ١٢٣ والفواصل)، التاريخ، التصنيف، الحالة،
  مع زر «حفظ وإضافة آخر» للتسجيل المتتابع.
- **التصنيفات**: تجهيزات المنزل، القاعة، الملابس، الذهب، أخرى + إضافة تصنيفات خاصة.
- **الحالات**: مطلوبة قريباً / تم شراؤها / معلقة، وزر «تم الشراء» بنقرة واحدة.
- **لوحة إحصاء**: الإجمالي، ما تم دفعه (مع شريط تقدّم)، المتبقي للمستحقات، وتوزيع حسب التصنيف.
- **تصفية وترتيب**: حسب الحالة، التصنيف، الشهر، البحث النصي؛ والترتيب حسب الأقرب استحقاقاً
  أو الأحدث أو الأعلى سعراً أو المضافة حديثاً.
- **تعديل وحذف** مع إمكانية «تراجع» بعد الحذف.
- **عدّ تنازلي** لموعد الزفاف وتنبيهات للبنود المتأخرة أو القريبة.
- **العملة تلقائياً** حسب منطقة الجهاز (د.ت، ر.س، د.إ…) مع أسماء أشهر محلية (جانفي/يناير).
- **يعمل دون إنترنت**: التعديلات تُحفظ على الجهاز وتُرسل تلقائياً عند عودة الاتصال.
- **قابل للتثبيت** على شاشة الهاتف (PWA).

## كيف تعمل المشاركة والحماية

- عند إنشاء دفتر يولَّد **رمز سري** من 16 حرفاً (≈ 80 بت)، ويُشارَك برابط دعوة أو واتساب.
- كل طلب يحمل الرمز في الترويسة `x-masareef-key`، والقاعدة **لا تخزّن الرمز**، بل بصمته SHA-256.
- سياسات RLS في Supabase لا تكشف لأي طلب إلا صفوف الدفتر المطابق لرمزه
  (لا قراءة ولا تعديل ولا حذف لدفاتر الآخرين).
- المزامنة اللحظية عبر قناة بث Supabase Realtime تحمل إشارة «تغيّر شيء» فقط بلا بيانات،
  مع تحديث دوري كل 30 ثانية وعند العودة إلى التطبيق كاحتياط.

## البنية

```
masareef/
  supabase/schema.sql       ← الجداول وسياسات RLS (مطبّقة: migration «masareef_init»)
  src/
    config.js               ← إعدادات Supabase والتصنيفات والحالات والعملات
    lib/
      api.js                ← طلبات Supabase + قناة المزامنة اللحظية
      syncStore.js          ← محرك المزامنة (تحديث فوري، طابور دون اتصال، دمج)
      stats.js · format.js  ← الإحصاء والتصفية والتنسيق العربي
      spaceKey.js           ← توليد رمز الدفتر وروابط الدعوة
    hooks/                  ← useMasareef · useToast
    components/             ← Welcome · Dashboard · Header · StatCards · Filters
                              ExpenseList · ExpenseForm · CategoryBreakdown · SettingsPanel …
```

- قاعدة البيانات: مشروع Supabase «Arem ACADEMY»، الجدولان `masareef_spaces` و `masareef_items`
  منفصلان تماماً عن جداول المنصة.
- لا يحتاج التطبيق أي متغيرات بيئة: المفتاح المنشور (publishable) آمن للمتصفح بطبيعته،
  ويمكن تغييره عبر `VITE_SUPABASE_URL` و `VITE_SUPABASE_PUBLISHABLE_KEY`.

## التشغيل والاختبار

```bash
cd masareef
npm install
npm run dev      # خادم التطوير
npm test         # اختبارات المنطق ومحرك المزامنة (Vitest)
npm run lint
npm run build
```

## النشر على Vercel

مشروع Vercel مستقل باسم **masareef** (Root Directory = `masareef`)، إعداداته في `vercel.json`.

- الرابط: **https://masareef-ochre.vercel.app**
- المشروع غير مربوط بالدفع التلقائي من Git (حتى لا تفشل بناءات الفروع التي لا تحتوي هذا المجلد)؛
  للتحديث: ادفع التعديلات ثم أنشئ نشراً إنتاجياً من الفرع (Vercel MCP `create_deployment` أو لوحة Vercel).

## إزالة التطبيق من قاعدة البيانات (عند الحاجة)

```sql
drop table if exists public.masareef_items, public.masareef_spaces;
drop function if exists public.masareef_request_space(), public.masareef_touch_updated_at();
```
