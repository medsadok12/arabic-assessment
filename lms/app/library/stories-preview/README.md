# العرض الخارجي للقصص

طلب صاحب المشروع تطبيق التصميم الخارجي فقط، وحظر أي تعديل غير مطلوب على عناصر القصص الداخلية.

- يعرض قسم حكاياتي داخل المكتبة التصميم الخارجي المعتمد: الترويسة والأغلفة والبطاقات والبحث والمستويات وعوالم القصص والمفضلة المؤقتة.
- البطاقات روابط مباشرة إلى مسار القصة الأصلي `/library/stories/[slug]`؛ لا قارئ بديل أو نافذة وسيطة.
- استُعيد `StoryFlipBook.jsx` حرفيًا إلى نسخته قبل بدء معاينات القصص (المرجع `84a81b0`). أُزيل قارئ المعاينة وأدوات تغيير تخطيط القراءة.
- `StoryReader` وصفحات القصص والتسجيلات وأزرار الاستماع والتنقل لم تُعدّل. لا كتابة إلى محتوى القصص أو التسجيلات أو التقدم أو النقاط.
- المفضلة محلية ومعزولة بحسب الحساب والطفل والتبويب، وحالة القراءة تُعرض من قراءة بيانات المنصة الموجودة فقط.
- تظل صفحة `/library/stories-preview` عرضًا لنفس الواجهة الخارجية وتفتح القارئ الأصلي نفسه.

أي تعديل مستقبلي يجب أن يقتصر على الجزء المطلوب صراحةً؛ تحسين عرض الأغلفة لا يجيز تغيير القارئ أو عناصره الداخلية.
