# أكتشف الأشياء

إضافة مستقلة إلى المكتبة: `/library/discover-objects`.
لوحة المعلمين والإدارة: `/library/discover-objects/manage`، أو زر «لوحة تحكم التدريب» داخل اللعبة.

- المشاهد والأشياء وصورها وخلفياتها ومواضعها وأحجامها، والألغاز وكلماتها وتلميحاتها وتسجيلاتها والجمل وإجاباتها، قابلة للإضافة والحذف والترتيب والتعطيل من اللوحة. استيراد/تصدير JSON للمحتوى.
- الإعدادات تحفظ في **صف خاص** `game_settings.game_id = 'discover_objects'`. يستخدم مخطط game_settings وgame_results وpoints الموجود، دون هجرة أو تغيير إعدادات لعبة أخرى. غياب الصف وحده يعيد المثال؛ خطأ القراءة لا يعيد محتوى قد أخفاه المعلم.
- الحفظ مشروط بنسخة `updated_at` لمنع الكتابة فوق تعديلات معلم آخر. المحرر يحتفظ بتعديلاته عند الفشل. المحتوى يجلب بلا كاش عند العودة للتبويب وكل دقيقة؛ تغيير نسخته يعيد الجولة كي لا تختلط إجابات قديمة بمحتوى جديد.
- الصور تصغّر قبل الرفع؛ الملفات في `media/discover-objects/` فقط. تسجيل المعلم أو ملفه الصوتي وحده: عنصر Audio مشترك بلا TTS، يتوقف عند الانتقال والمغادرة.
- التأكد من الإجابات والمكافأة على الخادم. النتائج بهوية الطفل النشط (`childFetch` + `resolveActiveIdentity`). لكل طفل/لغز حجز ذري بمفتاح نصي خاص `discover_objects:completed:<child>:<riddle>` في game_settings يمنع تكرار المطالبة حتى بالتوازي؛ بعد الحجز تستخدم awardPoints الموجودة، ثم حقول game_results نفسها المستخدمة في مسار النتائج القائم (بلا افتراض نوع id). تعارض الرصيد يحرّر الحجز لإعادة المحاولة. زيادة المكافأة لاحقًا لا تمنح اللغز القديم مرة أخرى؛ لإنجاز جديد أنشئ لغزًا جديدًا. معاينة الطاقم لا تكتب نتائج ولا تمنح نقاطًا.
- صلاحيات التحرير من getRole/app_metadata فقط؛ المعلم والمدير والمدير المطلق. لا أسرار في العميل، ولا مكتبات جديدة. CSS معزول تحت `#word-detective` و`#discover-editor`.
- نطاق التعديل خارج هذا المجلد: بطاقة جديدة في LibraryGrid، ومفتاح حالة إنجازها في صفحة المكتبة، ومسارات ومساعدات واختبارات خاصة بهذه اللعبة فقط. لم تتغيّر المصادقة أو النقاط المشتركة أو الألعاب القائمة.

التحقق: `npm test` و`npm run build` من `lms/`. اختبارات اللعبة في `lib/discover-objects*.test.js` تغطي التحقق من المحتوى والصلاحيات والحفظ المتعارض وعزل الأطفال وتكرار المكافآت والوسائط.

## صوت الكلمة والموسيقى

- `round.wordAudio` مستقل عن `round.audio` (الدليل): رفع أو تسجيل أو إزالة أو معاينة من لغز المشهد. يُسمع تسجيل الكلمة فور اكتشاف الشيء، وله زر إعادة سماع؛ لا نطق آلي عند غياب التسجيل.
- `config.sounds`: اختيار من 8 ألحان خلفية و8 ألحان نجاح أصلية في `lib/discover-objects-sounds.js`، أو ملف مرفوع لكل منهما، مع مستويات منفصلة للخلفية والنجاح والكلمة والدليل، وخيار تعطيل النطق التلقائي. الألحان المدمجة تُعزف محليًا بـWebAudio بلا مصادر خارجية.
- `createDiscoverAudio` يعزل الأصوات داخل التدريب: يوقف الخلفية مؤقتًا ← ينطق الكلمة ← يعزف النجاح ← يستأنف الخلفية. عنصر كلام واحد، وحماية من callbacks ورفض play القديم، وكتم للطالب وإيقاف كامل عند إخفاء التبويب والمغادرة. تسجيل الميكروفون يوقف المعاينة الصوتية قبله.
- تبدأ الخلفية بعد تفاعل المستخدم احترامًا لقيود المتصفح، وهي متوقفة افتراضيًا. الحقول الجديدة اختيارية للمحتوى القديم؛ `validateDiscover` يملؤها افتراضيًا دون تبديل أي مشهد أو نص أو تسجيل موجود، ودون هجرة قاعدة بيانات.
