# معاينة الأبطال الجدد — 2026-10-27

معاينة مؤقتة داخل `/dashboard/heroes-studio`، بناءً على طلب الأستاذ محمد مراجعة الشخصيات قبل اعتمادها. لا صفحة أو رابط تنقل جديد، ولا استبدال لكتالوج الشخصيات الحالي.

- `HeroesPreview.jsx` يعرض راشد ومنى وفِنّ وفهيم: اختيار، اسم مؤقت، إطار، إطلالتان، ثلاثة عوالم، تحية واحتفال، ومهمة توضيحية من ثلاث كلمات وشجرة محلية.
- كل الحالة في React فقط، وتُصفّر عند مغادرة المعاينة. لا fetch ولا تخزين أسماء، ولا نتائج أو نجوم أو مشتريات أو أوسمة رسمية. المهمة مثال ثابت للمراجعة وليست تدريبًا منشورًا أو معيارًا للإتقان.
- العرض الجديد مجسّمات إجرائية مبسّطة قابلة للتدوير، مع بقاء الصور الأصلية للمقارنة. لا توجد ملفات GLB ولا تطابق بصري كامل مع التصاميم الأصلية. اعتمادها وربطها بالتدريبات الرسمية ينتظر موافقة الأستاذ.
- قسم الأبطال الحالي هو العرض الافتراضي، وبطله واختياراته ومشترياته تبقى كما هي عند فتح المعاينة وإغلاقها. أزرار الشراء الأصلية مخفية أثناء المعاينة، ويتوقف صوت الشخصية الحالية عند التبديل.
- CSS خاص بالمكوّن. لا تغيير في API أو الجداول أو الصلاحيات أو قواعد المكافآت.

## الأصول

صور أصلية أُنتجت بأداة image_gen المدمجة ثم حُوّل تنسيقها إلى WebP، دون تغيير محتواها البصري. الملفات الثلاثة 1536×1024:

- `concept-board.webp`: لوحة التصميم المعروضة للأستاذ محمد، مع صور الوجوه وتعبيراتها.
- `characters.webp`: نفس هويات الشخصيات في شبكة 2×2، بخلفية كريمية خالية من النص: راشد أعلى اليسار، منى أعلى اليمين، فِنّ أسفل اليسار، فهيم أسفل اليمين.
- `explorer.webp`: نفس الترتيب والهويات بإطلالات استكشاف كريمية وزرقاء مخضرة.

مواصفة التوليد: شخصيات كرتونية ثلاثية الأبعاد محببة، ملامح ناعمة وعيون معبّرة، أجسام كاملة داخل شبكة 2×2، إضاءة استوديو ناعمة وخلفية كريمية، بلا نصوص أو شخصيات إضافية. صور الوجوه والإطلالات تُعرض بإطارات CSS من هذه الأصول؛ عند تغيير أبعاد الأصل يجب تحديث إحداثيات Portrait.

التحقق: اختبارات المنصة، بناء Next، وفحص متصفح للمكوّن والصفحة الفعليين على 320/390/820/1280، يتضمن العودة للتجربة الحالية، تبديل الإطلالات، الإجابة الخاطئة ثم الصحيحة، إكمال المهمة، وعدم إرسال أي كتابة. بديل رسم فقط للمحرك القديم في اختبار المتصفح؛ لا تعديل على محركه المنشور.

## تحديث المجسّمات — 2026-10-27

أصبحت مساحة العرض تستعمل مجسّمات إجرائية مبسّطة من `lib/heroes-preview3d.js` عبر المكوّن `HeroesPreview3D.jsx`: تدوير باللمس وأزرار، إطلالتان، تحية ومشي واحتفال. ليست المجسّمات تحويلًا مطابقًا للصور الأصلية؛ تبقى الصور في بطاقات الاختيار ولوحة المقارنة، وتظهر كبديل عندما لا يتوفر WebGL. الاختيارات مؤقتة ولا توجد عمليات كتابة للحساب. أُبقي نظام الأبطال والمشتريات الحالي مستقلاً.
